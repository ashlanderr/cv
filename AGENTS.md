## Code Rules

- Check types `npm run types` (tsc).
- Fix style `npm run lint` (eslint).
- Frontend is always running on http://localhost:5173
- Tailwind for styling.
- Nested components in pages and other components.
- Open browser and visually verify UI changes.
- Browser screenshot shows transient state? Screenshot again.
- Use standard APIs over manual implementations when they exist (Intl, Date, etc.).
- Use flex/grid to let UI push containers, don't hardcode sizes to fit content.
